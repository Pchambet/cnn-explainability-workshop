# Assets

`portrait.jpg`: astronaut Eileen Collins, NASA official portrait. Public domain (work of the
US federal government; "no known copyright restrictions" per the
[NASA Great Images](https://flic.kr/p/r9qvLn) release). Taken from scikit-image's copy,
[`skimage.data.astronaut`](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut)
(`astronaut.png`, 512 x 512), cropped to the box (75, 0, 375, 300) and saved as JPEG.

It replaces the portrait of the first version of this workshop, whose source and licence
could not be traced.
